# 缴费基数对账台（contribution-base）

公司按「最低基数」缴社保公积金，你当月到手是多了还是少了？这个页面把同一份规则下的两条路并排摆开，算清**五笔钱**：本月到手、进你个人账户、进统筹、公司为你掏的钱，以及 N 年后账户里差多少。

- 单文件前端应用（`index.html`），无网络请求、无依赖、不上传任何数据，保存只写浏览器 localStorage。
- 金额与费率全部由用户填写；**默认值与内置场景都是虚构示例，不是任何地区或年份的政策数值**。
- 内核：整数「分」账 + 逐险种归属分解（进个人账户 / 进统筹）+ 长期累积 + 解析反推（带整数微调）。

## 口径（页面内也逐条写明）

- 有效基数 = `clamp(申报基数, 下限, 上限)`；「足额」这一路用月工资本身再截断，不代表任何地区认定的应缴口径。
- 逐险种：`个人缴 = 基数 × 个人费率`、`公司缴 = 基数 × 公司费率`，各自四舍五入到分；再按「计入个人账户比例」拆成进个人账户与进统筹两份，余额进统筹。
- 公积金双边（个人 + 公司）**全额**进个人账户。
- 本月到手 = 月工资 − 个人缴费合计；**不扣个税**（本页不算个税）。
- 长期累积 = 每月账户增额按月复利累积 `年限 × 12` 个月；利率为 0 时是精确整数分，含利率时为浮点按月累加。
- 反推：先解解析式，再用实测局部斜率做牛顿迭代，最后在 ±64 分内做整数微调，使回代残差落在「月数 × 账户月增整分粒度」内。

## 不算什么（边界）

不判断「按低基数缴」是否合规，也不给举报、仲裁或谈判建议；不内置任何地区/年份的真实费率与上下限；不算个税；不算「退休后每月能领多少养老金」；不处理断缴、补缴、滞纳金、历年基数调整、年终奖与股权、多地重复参保、上下限随年份变动；医保个人账户计入规则由用户自己填。
